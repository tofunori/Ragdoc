# Historical Windows helpers

These scripts belong to the old Conda/menu workflow and are retained for reference.
They are not the current installer. Paths must be adapted to your own machine;
`setup_path.ps1` changes the user's PATH when run. Do not run it just to try Ragdoc.

Use the [current backend guide](../../../docs/installation.md) instead. Ragdrop is
a macOS application; the standalone backend has separate Python setup requirements.
