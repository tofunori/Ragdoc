# Ragdrop screenshots

These four PNGs are native captures of the actual Ragdrop 0.6 demonstration build,
not generated interface mockups. They show the same views as the normal app with
isolated synthetic data. The home views retain the visible demonstration strip.

| File | View |
|---|---|
| `home-light.png` | Import actions and synthetic recent articles, light theme |
| `home-dark.png` | The same workspace, dark theme |
| `review-light.png` | Original example PDF and rendered extraction, light theme |
| `review-dark.png` | The same review, dark theme; PDF colors remain unchanged |

The article titles, PDF text and table values are original examples generated by
`ReviewDemoFixtures` and `ThemeDemoApp`. They are not research findings or imported
journal articles. No personal library, credentials, private hostnames or actual
indexing results are shown. The small purple indicator in home captures belongs
to macOS screen capture, not the application. Captures are unaltered, under 100 KB
each; alt text is supplied where they appear in the documentation.

To reproduce the views, follow the [demo build instructions](../../../Ragdrop/README.md#try-the-interface),
choose the appearance in **Settings**, and use **Review** in the demonstration
strip to open the synthetic comparison. No OCR request or real import is needed.

The separate [README banner](../banner.png) is an AI-generated brand illustration,
not a software screenshot. It was made with the built-in image generator: a wide,
restrained off-white/graphite banner, muted teal highlights, abstract pages linked
to an index, and the text “Ragdoc + Ragdrop / Your scientific library. Connected.”
